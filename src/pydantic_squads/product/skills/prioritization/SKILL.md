# Prioritization

## When to Use This Skill

Use this skill whenever there is more than one candidate bet on the table and
the founder needs to know which one to pursue first, or whenever a bet's
priority needs to be justified with numbers instead of a gut feeling.

## Instructions

1. For each candidate bet, score **impact** (how much it moves the metric if
   it works), **confidence** (how sure we are it will work, given the
   evidence HX has surfaced) and **effort** (how much work it takes),
   each on a 1-10 scale. See `references/scoring.md` for the scale.
2. Compute a priority score per `references/scoring.md`.
3. Rank the bets by score, highest first.
4. State the score and its three components next to each bet, not just the
   rank — the founder needs to see *why*, not just *what*.
5. A bet resting on assumptions HX has not validated should be scored lower
   on confidence, never silently skipped.
